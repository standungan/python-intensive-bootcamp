Functions

Bungkus logika agar bisa dipakai berulang

Blok 80 menit: konsep (35) + latihan L1–L8 (45).

FunctionAnatomi function

def sapa(nama, sapaan="Halo"):
    """Mengembalikan kalimat sapaan."""
    return f"{sapaan}, {nama}!"

pesan = sapa("Rina")
print(pesan)
Halo, Rina!
Urutan klik: def (parameter, nilai default) → docstring → return → panggilan → hasil. Bedakan parameter (di def) dan argumen (saat memanggil).

Functionprint ≠ return

def kuadrat_print(x):
    print(x * x)

def kuadrat_return(x):
    return x * x

a = kuadrat_print(4)
b = kuadrat_return(4)
print(a, b + 1)
16None 17
Function tanpa return mengembalikan None — hasilnya tidak bisa dipakai untuk hitungan lanjut.
Jebakan klasik pemula. print hanya menampilkan; return mengirim nilai ke pemanggil. Tanya: kenapa a bernilai None?

Function*args & **kwargs

def rata_rata(*angka):
    return sum(angka) / len(angka)

def profil(**data):
    for k, v in data.items():
        print(f"{k}: {v}")

print(rata_rata(80, 90, 70))
profil(nama="Ani", prodi="IF")

Posisi bebas

*angka → tuple

(80, 90, 70)

Keyword bebas

**data → dict

{"nama": "Ani", "prodi": "IF"}

80.0nama: Aniprodi: IF
*args menampung argumen posisi berlebih sebagai tuple; **kwargs menampung keyword sebagai dict.

FunctionScope — local vs global

x = 10

def ubah():
    x = 99
    print("dalam:", x)

ubah()
print("luar:", x)
dalam: 99luar: 10
Mengubah variabel global dari dalam function? Pakai return (lebih aman) — bukan global.
x = 99 di dalam function membuat variabel baru yang lokal; x global tetap 10. Pada langkah 5 lihat kotak Global menyala.

Lambda, map, filter & Comprehension

Ringkas tanpa kehilangan kejelasan

Blok 40 menit: demo (20) + latihan L9–L13 (20).

Fungsionalmap & filter dengan lambda

kuadrat = list(map(lambda x: x * x, [1, 2, 3, 4]))
lulus = list(filter(lambda n: n >= 60, [80, 55, 90, 45]))
Klik berulang: tiap klik memproses satu elemen. map mengubah setiap elemen; filter menyaring (merah = ditolak).

FungsionalComprehension & sorted(key=…)

nilai = [80, 55, 90, 45, 70]
lulus = [n for n in nilai if n >= 60]
bonus = [n + 5 for n in nilai]
peta = {n: ("lulus" if n >= 60 else "remedi") for n in nilai}
urut = sorted(nilai, key=lambda n: -n)
print(lulus)
print(bonus)
print(peta)
print(urut)
[80, 90, 70][85, 60, 95, 50, 75]{80: 'lulus', 55: 'remedi', 90: 'lulus', 45: 'remedi', 70: 'lulus'}[90, 80, 70, 55, 45]
Empat pola: list comprehension dengan filter, transformasi, dict comprehension dengan ekspresi kondisional, dan sorted dengan key lambda.

Error Handling

Program tidak crash saat sesuatu salah

Blok 50 menit: konsep (25) + latihan L16–L18 (25).

Errortry / except / else / finally

def bagi_aman(a, b):
    try:
        hasil = a / b
    except ZeroDivisionError:
        return None
    else:
        return round(hasil, 2)
    finally:
        print("selesai dihitung")
Klik 2 = jalur error; klik 3 = jalur sukses. finally selalu berjalan di kedua jalur (cocok untuk menutup resource).

ErrorHasil nyata bagi_aman

print(bagi_aman(10, 4))
print(bagi_aman(1, 0))
selesai dihitung2.5selesai dihitungNone
Tangkap error yang spesifik (ZeroDivisionError), jangan except: kosong.
Perhatikan "selesai dihitung" tercetak pada kedua pemanggilan.

Errorraise — membuat error sendiri

def validasi_umur(umur):
    if not isinstance(umur, int):
        raise TypeError("umur harus int")
    if umur < 0:
        raise ValueError("umur tidak boleh negatif")
    return umur

for u in (25, -3, "dua"):
    try:
        print(validasi_umur(u))
    except (TypeError, ValueError) as e:
        print(type(e).__name__, "->", e)
25ValueError -> umur tidak boleh negatifTypeError -> umur harus int
raise menghentikan function & melempar error ke pemanggil; except … as e menangkapnya. Cocok untuk validasi input.

File Handling

Teks dan CSV — data yang bertahan

Blok 50 menit: demo (25) + latihan (25).

FileFile teks: with open & pathlib

from pathlib import Path
p = Path("catatan.txt")
p.write_text("baris 1\nbaris 2\n", encoding="utf-8")
with open(p, "a", encoding="utf-8") as f:
    f.write("baris 3\n")
for no, baris in enumerate(p.read_text(encoding="utf-8").splitlines(), 1):
    print(no, baris)
print(p.exists(), p.suffix)
1 baris 12 baris 23 baris 3True .txt
Selalu pakai with (file otomatis tertutup) dan encoding="utf-8".
Mode "w" menimpa, "a" menambah, "r" membaca.

FileCSV dengan DictWriter / DictReader

import csv
with open("nilai.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["nama", "nilai"])
    w.writeheader()
    w.writerows([{"nama": "Ani", "nilai": 85},
                 {"nama": "Budi", "nilai": 70}])
with open("nilai.csv", newline="", encoding="utf-8") as f:
    for baris in csv.DictReader(f):
        print(baris["nama"], int(baris["nilai"]) + 5)
Ani 90Budi 75
Nilai dari CSV selalu str → ubah dengan int(); newline="" saat menulis agar tidak ada baris kosong (Windows).
Tabel kanan = isi file setelah ditulis (klik 1) dan dibaca baris demi baris (klik 2).
