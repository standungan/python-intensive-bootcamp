Control Flow

Memilih cabang dan mengulang pekerjaan

Blok 60 menit: if (15) + for (15) + while (15) + latihan (15).

Percabanganif / elif / else — satu jalur dipilih

nilai = 78
if nilai >= 85:
    grade = "A"
elif nilai >= 70:
    grade = "B"
else:
    grade = "C"
print(grade)
Klik mengikuti alur untuk nilai = 78: 78 ≥ 85? tidak → 78 ≥ 70? ya → grade = "B". Hanya satu cabang yang dijalankan. Urutan cek: dari batas tertinggi.

Perulanganfor — ulangi untuk setiap elemen

for i in range(1, 6):
    print(i * i)

range(1, 6) menghasilkan

i * i pada tiap putaran

Setiap klik = satu putaran. Kotak oranye = nilai i saat ini. Kotak bawah menampilkan hasil i * i. Ingat: range(1, 6) berhenti di 5 (akhir eksklusif).

Perulanganwhile — ulangi selama kondisi benar

sisa = 3
while sisa > 0:
    print(sisa)
    sisa -= 1
print("selesai")
321selesai
Tanpa sisa -= 1 → loop tak berhenti!
Ikuti satu putaran demi satu: cek kondisi → jalankan badan → cek lagi. Pada langkah akhir kondisi False → keluar. Tunjukkan bahaya loop tak-hingga (tekan Ctrl+C / Interrupt kernel).

Struktur dataList — urutan yang bisa diubah

nilai = [80, 90, 75, 88]
print(nilai[0])
print(nilai[-1])

nilai.append(95)

Kunci: indeks mulai 0, indeks negatif dari belakang, irisan akhir eksklusif. Langkah terakhir: append menambah di ujung.

Struktur dataDictionary — pasangan key → value

mhs = {
    "nama": "Budi",
    "nim": "2201",
    "ipk": 3.6,
}
print(mhs["nama"])
print(mhs.get("prodi", "belum diisi"))
mhs["prodi"] = "Informatika"
mhs["ipk"] = 3.7
Budibelum diisi
Akses langsung mhs["prodi"] yang belum ada → KeyError; .get(key, default) aman.
Pada langkah 3 kunci "prodi" tidak ada → .get memberi nilai default (tidak error). Langkah 4: menambah key baru. Langkah 5: mengubah nilai ipk.

Struktur dataSet — unik & operasi himpunan

a = {"baca", "musik", "olahraga"}
b = {"musik", "gaming", "olahraga"}
print(a | b)   # gabungan
print(a & b)   # irisan
print(a - b)   # hanya di a
Hapus duplikat: list(set([1, 2, 2, 3])) → [1, 2, 3]
Venn: kiri = hanya a, tengah = irisan, kanan = hanya b. Set tidak berurutan & tidak punya duplikat.

Struktur dataList of dict — pola data mahasiswa

mahasiswa = [
    {"nama": "Ani",  "ipk": 3.5, "prodi": "IF"},
    {"nama": "Budi", "ipk": 3.9, "prodi": "SI"},
    {"nama": "Cici", "ipk": 3.2, "prodi": "IF"},
]
if_only = [m for m in mahasiswa if m["prodi"] == "IF"]
terbaik = max(mahasiswa, key=lambda m: m["ipk"])
IF → Ani, Ciciipk tertinggi → Budi
Ini struktur utama mini project. List = kumpulan baris, setiap dict = satu mahasiswa. Filter dengan list comprehension; max(..., key=lambda ...) untuk nilai tertinggi.
