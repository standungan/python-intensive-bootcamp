Instal Python

Cek dulu, instal bila perlu

15 menit: cek versi (3) + instal per OS (8) + jebakan PATH (4).

PythonCek: apakah Python sudah ada?

# macOS / Linux

Yang dicari: Python 3.11 atau lebih baru (3.12, 3.13 juga baik).
Muncul "not recognized" / "command not found" → Python belum terpasang atau belum masuk PATH. Lanjut ke slide berikutnya.
Minta semua peserta mengetik perintah dan menyebutkan hasilnya. Di macOS/Linux, python bisa tidak ada tetapi python3 ada — itu normal.

PythonInstal Python sesuai sistem operasi

Windows

  • unduh installer dari python.org/downloads
  • jalankan, centang “Add python.exe to PATH”
  • pilih Install Now

macOS

  • unduh installer dari python.org/downloads
  • atau Homebrew: brew install python

Linux

  • Debian/Ubuntu:
  • sudo apt install python3 python3-venv python3-pip
  • Fedora: sudo dnf install python3
Setelah instal, tutup dan buka lagi terminal, lalu ulangi perintah cek versi.
Kotak “Add python.exe to PATH” di installer Windows adalah sumber masalah nomor satu — tunjukkan layar installer. Di Ubuntu, paket python3-venv diperlukan agar python3 -m venv berfungsi.

Virtual Environment (venv)

Lingkungan terisolasi untuk tiap proyek

15 menit: konsep (4) + buat & aktifkan (8) + jebakan PowerShell (3).

venvMengapa perlu venv?

Tiap proyek punya paket sendiri → tidak bentrok, mudah dihapus, mudah diulang di komputer lain.
Analogi: satu kotak peralatan per proyek. Tanpa venv, memperbarui satu paket untuk proyek A bisa merusak proyek B.

venvBuat dan aktifkan venv

1 · Buat (sekali saja)

python -m venv .venv      # macOS/Linux: python3 -m venv .venv

2 · Aktifkan (setiap membuka terminal baru)

SistemPerintah
Windows PowerShell.venv\Scripts\Activate.ps1
Windows CMD.venv\Scripts\activate.bat
macOS / Linuxsource .venv/bin/activate
Berhasil bila prompt berawalan (.venv), misalnya (.venv) PS C:\bootcamp> atau (.venv) user@pc:~/bootcamp$.
Demo langsung. Perintah buat hanya sekali per proyek; perintah aktifkan diulang setiap kali membuka terminal baru. Tunjukkan folder .venv yang muncul.

venvJebakan Windows: skrip dinonaktifkan

Gejala di PowerShell

Activate.ps1 cannot be loaded because running scripts is disabled on this system.

Solusi (pilih satu)

# A. izinkan skrip lokal untuk akun Anda
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# B. atau pakai CMD
.venv\Scripts\activate.bat
Ini hanya terjadi di PowerShell Windows. Opsi A cukup dijalankan sekali; jawab Y bila diminta konfirmasi. Opsi B menghindari masalah dengan memakai CMD.

venvCek venv sudah aktif

python -c "import sys; print(sys.prefix)"
python -m pip --version
deactivate
Baris pertama harus menunjuk ke folder .venv di dalam bootcamp.
Baris kedua menampilkan lokasi pip di dalam .venv.
deactivate keluar dari venv; prompt kembali normal.
Jika path tidak menunjuk ke .venv, venv belum aktif — kembali ke langkah aktivasi. Setelah deactivate, aktifkan lagi sebelum lanjut.

Jupyter Notebook

Menulis dan menjalankan kode per sel

15 menit: menjalankan (5) + antarmuka (5) + kernel venv (5).

JupyterMenjalankan Jupyter

jupyter notebook
Biarkan terminal tetap terbuka selama bekerja. Berhenti dengan Ctrl+C di terminal.
Browser tidak terbuka sendiri? Salin alamat http://localhost:8888/… (lengkap dengan token) dari terminal.
Jupyter berjalan sebagai server di komputer Anda sendiri; browser hanya antarmukanya. Jika port 8888 terpakai, Jupyter otomatis memakai 8889 dan seterusnya.

Jika kode aneh/error tak masuk akal: menu Kernel → Restart Kernel and Run All Cells.
Ada dua jenis sel: kode dan Markdown. Variabel hidup di kernel, jadi urutan menjalankan sel penting. Tunjukkan satu sel kode print("halo").

JupyterPastikan kernel memakai venv

# di terminal, venv aktif
pip install ipykernel
python -m ipykernel install --user --name bootcamp --display-name "Python (bootcamp)"
Jupyter yang dijalankan dari venv otomatis memakai venv itu.
Perintah kedua mendaftarkan venv sebagai kernel yang bisa dipilih: Kernel → Change kernel → Python (bootcamp).
Cek di sel: import sys; sys.executable → harus menunjuk ke folder .venv.
Penyebab klasik ModuleNotFoundError di notebook: kernel yang dipakai bukan venv (paket terpasang di venv, tetapi notebook jalan di Python lain). Tanpa --display-name, kernel baru akan bernama generik sehingga membingungkan.
