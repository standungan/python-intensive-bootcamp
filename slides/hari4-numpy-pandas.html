NumPyMengapa array, bukan list?

import numpy as np
list_a = [1, 2, 3]
arr = np.array([1, 2, 3])
print(list_a * 2)
print(arr * 2)
print(arr.dtype, arr.shape)
[1, 2, 3, 1, 2, 3][2 4 6]int64 (3,)
Operasi array berlaku untuk seluruh elemen sekaligus (vectorized) — lebih ringkas dan jauh lebih cepat.
list * 2 menggandakan list; array * 2 mengalikan tiap elemen.

NumPyIndexing & slicing 2D

import numpy as np
arr = np.arange(12).reshape(3, 4)
print(arr[1, 2])
print(arr[:, 1])
print(arr[0:2, 1:3])
6[1 5 9][[1 2] [5 6]]
Format: arr[baris, kolom]. : = semua. 0:2 = baris 0 dan 1 (akhir eksklusif).

NumPyBoolean masking & np.where

import numpy as np
nilai = np.array([55, 80, 45, 90, 70])
lulus = nilai >= 60
print(lulus)
print(nilai[lulus])
print(np.where(nilai >= 60, "lulus", "remedi"))
[False True False True True][80 90 70]['remedi' 'lulus' 'remedi' 'lulus' 'lulus']
Mask berisi True/False per elemen; nilai[mask] mengambil yang True. np.where = if-else untuk seluruh array.

NumPyAgregasi per axis & broadcasting

import numpy as np
m = np.array([[1, 2, 3], [4, 5, 6]])
print(m.sum(axis=0))
print(m.mean(axis=1))
print(m + np.array([10, 20, 30]))
[5 7 9][2. 5.][[11 22 33] [14 25 36]]
axis=0 → turun per kolom · axis=1 → menyamping per baris. Broadcasting: vektor 3 elemen "ditarik" ke kedua baris.
Klik 1: axis=0 (biru, per kolom). Klik 2: axis=1 (hijau, per baris). Klik 3: broadcasting menambah vektor ke setiap baris.

CleaningMissing values & duplikat

import pandas as pd, numpy as np
df = pd.DataFrame({"nama": ["Ani", "Budi", "Budi", "Cici"], "nilai": [80, np.nan, np.nan, 70]})
print(df.isna().sum())
df = df.drop_duplicates()
df["nilai"] = df["nilai"].fillna(df["nilai"].mean())
print(df)
nama 0nilai 2dtype: int64 nama nilai0 Ani 80.01 Budi 75.03 Cici 70.0
Klik: temukan NaN → hapus duplikat (baris 2) → isi NaN dengan rata-rata (75.0).

Pandasgroupby — pisah, hitung, gabung

df.groupby("prodi")["ipk"]
  .agg(["mean", "count"])
mean countprodi IF 3.35 2SI 3.75 2

Split → Apply → Combine

IF: (3.5+3.2)/2 = 3.35. SI: (3.9+3.6)/2 = 3.75. Grafik muncul bertahap saat Anda klik.

Pandasmerge — gabung tabel lewat kunci

nim nama skor0 1 Ani 90.01 2 Budi 80.02 3 Cici NaN
how="left" mempertahankan semua baris kiri; yang tak punya pasangan → NaN. Tipe kolom kunci harus sama!
Klik 1: kolom kunci. Klik 2: baris yang cocok (hijau) vs tidak (redup). Klik 3: hasil gabungan.

Pandaspivot_table — ringkasan dua dimensi

df.pivot_table(index="prodi", columns="angkatan",
               values="ipk", aggfunc="mean")
angkatan 2023 2024prodi IF 3.5 3.2SI 3.9 3.6
Baris = prodi, kolom = angkatan, isi = rata-rata ipk.
