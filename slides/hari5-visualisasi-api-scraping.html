API & JSON

Meminta data dari server

Blok 60 menit: konsep (35) + latihan L9–L11 (25).

APIAlur request → response

r = requests.get(url, params={"limit": 3}, timeout=10)
r.raise_for_status()      # error bila 4xx/5xx
data = r.json()
Selalu pakai timeout dan raise_for_status(). Kode status: 2xx sukses, 4xx salah di klien, 5xx salah di server, 429 = terlalu sering.

APIJSON → dict → DataFrame

import json, pandas as pd
raw = respons_json
d = json.loads(raw)
print(d["data"][0]["kota"]["nama"])
df = pd.json_normalize(d["data"])
print(df)
Bandung id nama kota.nama0 1 Ani Bandung1 2 Budi Medan
json_normalize meratakan JSON bersarang jadi kolom: kota.nama.
Pada contoh ini respons_json adalah string JSON (dari r.text) berisi daftar pengguna dengan objek bersarang.

APIError handling jaringan

import requests
def ambil(url):
    try:
        r = requests.get(url, timeout=5)
        r.raise_for_status()
        return r.json()
    except requests.exceptions.RequestException as e:
        print("Gagal:", type(e).__name__)
        return None
KodeArti
200OK
404tidak ditemukan
429terlalu sering — tunggu
5xxserver bermasalah
Siapkan fallback: cache lokal / data contoh agar program tetap jalan offline.
Satu except requests.exceptions.RequestException menangkap Timeout, ConnectionError, HTTPError.

ScrapingEtika scraping

  • Baca robots.txt dan Terms of Service situs
  • Beri jeda antar request (rate limit), jangan membanjiri server
  • Utamakan API resmi bila tersedia
  • Jangan ambil data pribadi / yang dilindungi
  • Cantumkan sumber data pada laporan
Tekankan etika sebelum teknik.
