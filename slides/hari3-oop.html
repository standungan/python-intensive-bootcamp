Cetak biru dan benda nyata

OOPClass = cetak biru, object = benda

class Mahasiswa:
    def __init__(self, nama, ipk):
        self.nama = nama
        self.ipk = ipk

    def info(self):
        return f"{self.nama} (IPK {self.ipk})"

m1 = Mahasiswa("Ani", 3.7)
m2 = Mahasiswa("Budi", 3.2)
print(m1.info())
Ani (IPK 3.7)
Klik: class (cetak biru) → __init__ → method → object m1 dan m2 muncul di kanan, masing-masing punya data sendiri. self = object yang sedang dipakai.

OOPClass attribute vs instance attribute

class Siswa:
    sekolah = "SMA 1"        # class attribute
    jumlah = 0

    def __init__(self, nama):
        self.nama = nama     # instance attribute
        Siswa.jumlah += 1

a, b = Siswa("Ani"), Siswa("Budi")
print(a.nama, b.nama, a.sekolah, Siswa.jumlah)
Ani Budi SMA 1 2
Class attribute: dibagi semua object (mis. penghitung). Instance attribute: milik object masing-masing.
Penghitung Siswa.jumlah bertambah setiap object dibuat — contoh umum class attribute.

Inheritance & Polimorfisme

Mewarisi dan menimpa perilaku

Blok 60 menit: konsep (25) + latihan L4–L5 (35).

OOPInheritance & override

class Hewan:
    def __init__(self, nama):
        self.nama = nama
    def suara(self):
        return "..."

class Kucing(Hewan):
    def suara(self):
        return "meong"

class Anjing(Hewan):
    def __init__(self, nama, ras):
        super().__init__(nama)
        self.ras = ras
    def suara(self):
        return "guk"

for h in (Kucing("Mimi"), Anjing("Rex", "Husky")):
    print(h.nama, h.suara())
Mimi meongRex guk
Hewan = induk. Kucing menimpa suara(). Anjing menambah attribute ras dan memanggil super().__init__. Loop akhir = polimorfisme: pemanggilan sama, perilaku berbeda.

Lupa memanggil super().__init__()

class Anjing(Hewan):

AttributeError: 'A' object has no attribute 'nama'

Benar

        self.ras = ras
Rex Husky
Jebakan nomor 1 pada inheritance: attribute induk "kosong" karena super().__init__() tidak dipanggil.

Encapsulation, Special Methods & Context Manager

Menjaga data dan membuat object "berperilaku Python"

Blok 70 menit: konsep (35) + latihan L6–L9 (35).

OOPEncapsulation — pintu resmi

class Rekening:
    def __init__(self, saldo=0):
        self._saldo = saldo

    @property
    def saldo(self):
        return self._saldo

    def setor(self, jumlah):
        if jumlah <= 0:
            raise ValueError("jumlah harus > 0")
        self._saldo += jumlah

r = Rekening(100)
r.setor(50)
print(r.saldo)

Mengapa?

Data _saldo dilindungi.

Ubah lewat setor() yang memvalidasi.

150
r.setor(-5) → ValueError: jumlah harus > 0
Awalan _ = "jangan sentuh langsung". @property membuat r.saldo bisa dibaca seperti attribute tapi tidak diubah sembarangan. Setoran negatif ditolak oleh setor().

OOPSpecial methods

class Buku:
    def __init__(self, judul, tahun):
        self.judul, self.tahun = judul, tahun
    def __str__(self):
        return f"{self.judul} ({self.tahun})"
    def __repr__(self):
        return f"Buku({self.judul!r}, {self.tahun})"
    def __eq__(self, other):
        return self.judul == other.judul

b1, b2 = Buku("Python", 2024), Buku("Python", 2024)
print(b1)
print(repr(b1))
print(b1 == b2, b1 is b2)
MethodDipanggil saat
__str__print(obj)
__repr__debug / repr()
__eq__a == b
Python (2024)Buku('Python', 2024)True False
__str__ harus return string — bukan print.
Tanpa __str__, print(obj) hanya menampilkan alamat memori.

OOPContext manager — with

class FileCatatan:
    def __init__(self, nama):
        self.nama = nama
    def __enter__(self):
        print("buka", self.nama)
        return self
    def __exit__(self, tipe, nilai, tb):
        print("tutup", self.nama)

with FileCatatan("log.txt") as f:
    print("bekerja dengan", f.nama)
buka log.txtbekerja dengan log.txttutup log.txt
__exit__ selalu dipanggil — walau terjadi error di dalam blok. Itulah alasan with open(...) aman.

JebakanMutable default argument

class Keranjang:
    def __init__(self, isi=[]):
        self.isi = isi

a, b = Keranjang(), Keranjang()
a.isi.append("apel")
print(b.isi)
['apel']

Semua object berbagi list yang sama!

def __init__(self, isi=None):
    self.isi = isi or []

Perbaikan: default None

Default dievaluasi sekali saat function didefinisikan, bukan setiap dipanggil.
